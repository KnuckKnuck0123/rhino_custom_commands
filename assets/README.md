# Array Tools icon

`array-tools-icon.png` is the initial project icon, generated with the built-in
OpenAI image-generation tool. It is used in the repository README. It is not yet
wired into a published Rhino package. The full generated PNG is preserved here;
final package/toolbar export sizes can be prepared when the package identity is set.

## Generation prompt

Create a polished square app icon for a Rhino 3D architectural design plugin called Array Tools, no text or letters. A clear, bold isometric aggregation of nine small architectural cuboids, orderly at the lower left then gradually shifting, rotating and increasing in height toward the upper right, expressing array variation. Restrained teal and warm ivory solid faces, deep charcoal background with slightly rounded square corners. Crisp geometric silhouette, strong contrast, generous 12 percent inset safe area, excellent readability as a 64 pixel icon. Flat vector-like rendering with subtle isometric depth, no fine wire grids, no photorealism, no gradients, no shadows outside the icon, no Rhino logo, no border, no labels. Output one centered finished icon, not a mockup or a sheet of variants.
